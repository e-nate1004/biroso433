# 비로소4'33'' 이용안내 웹북

제주 서귀포 남원리 비로소433 게스트용 이용안내 웹북입니다.

- 게스트용 주소: https://biroso433.com/ (예전 주소 e-nate1004.github.io/biroso433/ 는 자동 연결)
- 현재 버전: **v1.0** (2026-10-23)

## 파일
| 파일 | 내용 |
|---|---|
| index.html | 웹북 본문 (한·영·중·일 4개 언어) |
| manifest.webmanifest | 홈 화면 추가용 앱 설정 (이름·아이콘·색) |
| icon-180/192/512.png | 홈 화면 아이콘 (손그림 건물 스케치) |
| assets/icon-source.png | 아이콘 원본 이미지 |
| assets/qr-guest-guide.svg | 게스트용 QR코드 (벡터) |
| assets/Guest_Guide_QR_A5.jpg | 객실 비치용 QR 안내문 (A5, 300dpi) |
| CHANGELOG.md | 전체 작업 기록 |

## 수정 원칙
1. 수정안과 미리보기를 먼저 확인받는다.
2. 승인 후 Claude 이용안내 웹북·검수본·이 저장소 세 곳에 동시 반영한다.
3. CHANGELOG.md에 기록하고, 큰 변경은 버전 태그(v1.1, v2.0 …)를 단다.
