예약 손님 목록을 불러오면 오늘 체크아웃 · 오늘 체크인 · 예약 확정 순서로 보낼 문자를 정리해 드려요.

열린 구글 캘린더 화면에서 확인 후 저장만 누르세요. 캘린더는 비로소 예약, 막대는 박 수만큼 맞춰져 있어요.

문자 언어

처음에 보이는 "홍길동"과 번호는 예시예요. 새 손님을 누르고 실제 연락처를 넣으세요.

문자 3종

문자 길이: 한글은 2바이트, 영문·숫자는 1바이트로 셉니다. 90바이트까지 단문(SMS), 넘으면 장문(LMS)으로 보내져요. 문자 앱이 열리지 않으면 복사 버튼으로 내용을 복사해 붙여 넣으세요.

예약을 한 번에 불러오는 방법

구글 캘린더 · 비로소 예약 (추천)
  1. 사장님이 보내 준 설정 링크를 이 휴대폰에서 한 번 열면 연결돼요. 그다음부터는 이 페이지를 열 때마다 예약을 자동으로 불러와요.
  2. 예약은 공용 계정(biroso433stay)의 비로소 예약 캘린더에 넣어요.
  3. 제목: 3 홍길동 010-1234-5678 · 맨 앞 숫자는 방번호(없어도 돼요) · 외국 손님은 뒤에 EN 中 日
  4. 베드·인원·요청 사항은 제목이 아니라 일정 설명에 적어요.
  5. 날짜: 체크인 날 ~ 마지막 밤(체크아웃 전날), 종일로 저장. 막대 칸 수가 곧 박 수예요 (1박 = 하루, 2박 = 이틀).
안드로이드 · 공유로 불러오기
  1. 이 페이지를 크롬으로 열고 ⋮ → 홈 화면에 추가 (앱 이름: 비로소 레터)
  2. 한 분: 연락처 앱에서 손님을 열고 공유 → 비로소 레터. 손님 정보가 바로 채워져요.
  3. 오늘의 레터: 연락처 앱 검색창에 박 입력 → 하나를 길게 눌러 전체 선택 → 공유 → 비로소 레터. 예약 손님만 한 번에 정리돼요.
  4. 공유 목록에 비로소 레터가 없으면 공유 방식을 파일(VCF)로 고르거나, 위의 연락처에서 여러 분 고르기를 쓰세요.
아이폰 · 단축어 두 개 만들기

단축어 앱에서 한 번만 만들어 두면 돼요. 동작 이름은 단축어 앱의 검색창에 그대로 입력하면 찾을 수 있어요.

레터 쓰기 한 분을 공유로 불러오기

  1. 단축어 앱 → + → 이름을 레터 쓰기로 바꾸기
  2. 아래 ⓘ(설정) → 공유 시트에서 보기 켜기, 받는 입력은 연락처만
  3. 동작 텍스트 추가 → 내용: 단축어 입력의 이름 · 띄어쓰기 · 단축어 입력의 전화번호
  4. 동작 URL 인코딩 추가 (입력: 텍스트)
  5. 동작 URL 열기 추가 → 주소: https://biroso433.com/staff/#c= 바로 뒤에 URL 인코딩된 텍스트

사용: 연락처에서 손님 → 연락처 공유 → 레터 쓰기

오늘의 레터 예약 손님 목록 한 번에

  1. 새 단축어 → 이름 오늘의 레터
  2. 동작 연락처 찾기 → 필터 추가: 이름 · 다음을 포함 · 박
  3. 동작 각 항목을 반복 → 안에 텍스트: 반복 항목의 이름 · 띄어쓰기 · 반복 항목의 전화번호
  4. 반복 끝 다음에 텍스트 결합 (구분자: 새로운 줄)
  5. URL 인코딩 → URL 열기: https://biroso433.com/staff/#list= 바로 뒤에 URL 인코딩된 텍스트
  6. 단축어를 길게 눌러 홈 화면에 추가

사용: 아침에 홈 화면의 오늘의 레터를 누르면 오늘 보낼 문자가 정리돼 열려요.

불러온 연락처와 보낸 기록은 이 휴대폰에만 남고 어디에도 올라가지 않아요. 보낸 기록은 스탭마다 따로예요.

게스트용 QR 이미지

주소 biroso433.com 으로 연결돼요.

  • 이미지를 길게 눌러 저장하거나 복사한 뒤, 문자나 카카오톡에 첨부하세요.
  • 휴대폰으로 받은 손님은 링크를 바로 누르면 돼요. QR은 프런트 화면이나 출력물에 보여 줄 때 특히 편해요.
  • 아이폰은 사진 앱에서 QR 이미지를 길게 누르면, 안드로이드는 구글 렌즈로 바로 열 수 있어요.
