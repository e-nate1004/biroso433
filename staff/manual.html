1. 하루 흐름

  1. 예약을 받으면 → 레터의 예약 넣기에 적고 구글 캘린더에 넣기 → 열린 화면에서 저장
  2. 매일 아침 → 레터를 열면 오늘의 레터에 오늘 보낼 문자가 정리돼 있어요
  3. 손님마다 문자 보내기 → 문자 앱에서 내용 확인 후 전송 → 목록에 보냄 ✓

보낸 기록은 각자 휴대폰에만 남아요. 같은 손님에게 두 번 보내지 않도록 보내기 전에 ✓ 표시를 확인하세요.

2. 예약 넣기

예약을 받자마자 쓰는 칸이에요. 다 채우고 구글 캘린더에 넣기를 누르면 구글 캘린더 새 일정 화면이 미리 채워져 열립니다. 내용을 확인하고 저장만 누르면 끝.

  • 안드로이드: 버튼이 구글 캘린더 앱에 넣기로 보이고, 구글 캘린더 앱의 새 일정 화면이 열려요. 앱 화면 위쪽의 캘린더가 비로소 예약인지 꼭 확인하고 저장하세요. 앱이 없거나 잘 안 열리면 옆의 앱 대신 웹으로 열기.
  • 아이폰: 구글 캘린더 웹 화면이 열려요(캘린더는 비로소 예약으로 미리 골라져 있음). 글씨가 작으면 두 손가락으로 벌려 확대하세요.
예) 방 2번룸 · 한국어 · 홍길동 · 010-1234-5678 · 체크인 10/25 · 체크아웃 10/27 · 메모 퀸 / 2인
→ 캘린더 제목 2 홍길동 010-1234-5678, 10/25~10/26 막대 두 칸(2박), 캘린더 비로소 예약

방

1번룸~6번룸 중 하나. 정해지지 않았으면 미정. 방번호가 캘린더 제목 맨 앞에 들어가서 달력에서 어느 방인지 바로 보여요. 방이 바뀌면 캘린더 일정 제목의 맨 앞 숫자만 고치면 돼요. 방 구성은 객실 정보.

문자 언어

외국 손님이면 English · 中文 · 日本語. 제목 끝에 EN 中 日이 붙고, 오늘의 레터가 그 언어로 문자를 만들어요.

손님 이름

예약자 이름. 문자의 "OOO님"에 그대로 들어가요. 같은 날 같은 이름이 두 분이면 홍길동 1, 홍길동 2. 박 수·인원·재방 같은 표시는 이름 말고 메모에.

전화번호

문자를 받을 손님 휴대폰 번호 하나(010…). 하이픈은 있어도 없어도 돼요. 현금영수증·사업자 번호는 메모에. 번호를 모르면 아직 넣을 수 없어요.

체크인

손님이 도착하는 날. 고르면 체크아웃이 다음 날로 먼저 채워져요.

체크아웃

손님이 떠나는 날. 박 수 = 체크아웃 − 체크인. 캘린더 막대는 체크인 날부터 마지막 밤까지만 그려져요.

25일 밤26일 밤27일 아웃28일

체크아웃이 체크인과 같거나 빠르면 버튼이 눌리지 않아요.

메모

베드·인원·요청 사항을 자유롭게. 캘린더 일정의 설명에 들어가고 문자에는 들어가지 않아요. 예: 퀸 / 2인 / 재방 / 현금영수증 010-…

계정 (여러 개일 때)

휴대폰이나 컴퓨터에 구글 계정이 여러 개라 다른 계정의 캘린더가 열릴 때만 적어요. 비로소 예약을 공유받은 계정 이메일을 한 번 적으면 그 기기에 기억돼요.

3. 캘린더에 직접 넣을 때 (예약 넣기를 못 쓸 때)

  • 캘린더: 반드시 비로소 예약 (기본값이 다른 캘린더라 꼭 바꾸기)
  • 제목: 방번호 이름 전화번호 · 외국 손님은 끝에 EN 中 日 — 예) 3 홍길동 010-1234-5678
  • 종일 켜고, 시작 = 체크인 날, 끝 = 마지막 밤(체크아웃 전날) → 막대 칸 수 = 박 수
  • 베드·인원·요청은 제목이 아니라 설명에
  • 예약 취소 → 일정 삭제 · 날짜 변경 → 일정 옮기기

네이버에서 옮겨 온 예전 예약(셋2, 트5, 재방 등)은 표기를 그대로 두었어요.

4. 오늘의 레터

예약 목록을 불러와 오늘 보낼 문자를 오늘 체크아웃 → 오늘 체크인 → 예약 확정 순서로 보여 줘요. 각 줄에 방 · 체크인 날짜 · 박 수 · 번호가 보여요.

  • 캘린더 새로 불러오기: 비로소 예약 캘린더에서 최신 예약을 다시 받아요
  • 문자 보내기: 문자 앱이 내용이 채워진 채로 열려요. 확인하고 보내세요
  • 자세히: 그 손님을 아래 손님 정보로 불러와 문구를 보거나 고쳐요
  • 전화번호가 없는 일정은 목록에서 빠지고, 몇 개가 빠졌는지 아래에 적혀요

5. 레터 쓰기 · 한 분

한 분에게만 문자를 쓸 때. 연락처 이름과 번호를 붙여 넣으면 체크인 날짜 · 박 수 · 이름 · 번호가 손님 정보에 채워져요. 예) 0325 2박 홍길동 010-1234-5678

6. 손님 정보

문자에 들어갈 값을 직접 고치는 곳. 바꾸면 문자 3종이 바로 바뀌어요. 숙소 연락처는 비워 두면 문자에서 빠져요.

7. 문자 3종

  • 예약 확정: 예약을 받은 뒤 (체크인 전날까지)
  • 체크인 당일: 체크인 날 (이른 체크인 안내 포함)
  • 체크아웃 안내: 체크아웃 날 아침 (늦은 체크아웃 안내 포함)

90바이트까지 단문, 넘으면 장문으로 보내져요. 문자 앱이 열리지 않으면 복사해서 붙여 넣으세요. 문구는 사장님 확인 없이 바꾸지 않아요.

9. 자주 묻는 것

캘린더에 넣었는데 오늘의 레터에 안 나와요

  • 캘린더 새로 불러오기를 눌러 보세요
  • 캘린더가 비로소 예약인지, 제목에 010 전화번호가 있는지 확인
  • 오늘 보낼 차례가 아닌 손님은 목록에 없어요 (체크인 당일·체크아웃 날·예약 확정 대상만)

박 수가 하루 다르게 나와요

막대가 체크아웃 날까지 그려져 있으면 하루 더 계산돼요. 일정 끝 날짜를 체크아웃 전날로 고치세요. 예약 넣기로 넣으면 자동으로 맞춰져요.

다른 계정 캘린더가 열려요

예약 넣기 맨 아래 계정 칸에 비로소 예약을 공유받은 이메일을 적어 두세요.
